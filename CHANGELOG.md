# Changelog

## x.x.x

### Added

- Optional Claims skill with permanent city, membership, expansion, resistance, and personal plot unlocks
- Raidable lodestone anchors with persistent shared block resistance and manual administrative XP grants
- Claim boundaries, invitations, membership commands, and confirmed anchor removal
- Claim protection for teleportation, flight, indirect block changes, and Adapt abilities

### Changed

- Claims adaptation menus include controls, raid rules, entry restrictions, and ownership guidance

### Fixed

- Claimed containers require unobstructed physical reach for remote access
- Claims limits follow purchased ranks, power-budget changes, and adaptation configuration
- Temporary region grants cannot activate Claims unlocks
- Cancelled final raid actions retain their previous resistance progress
- Missing or immediately replaced breached anchors release their ownership
- A failed dismantle request clears its previous confirmation target
- Claims creation, expansion, invitations, and personal plots honor skill and adaptation use permissions
